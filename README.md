# 🌍 Global Clash Cup

**Build your base. Rally your clan. Raid for the crown!**

Global Clash Cup is a fan-made website concept for a Clash of Clans esports tournament. It showcases competitive clan battles, a King of the Hill challenge, event information, and useful Clash of Clans community resources.

## 📌 About the Project

The purpose of this project is to create a simple, visually engaging website for a fictional Clash of Clans tournament. The website presents tournament activities and provides links to resources for players interested in competitive gameplay.

## ✨ Features

- **Navigation Bar:** Navigate between the About, Schedule, and Links sections.
- **Tournament Information:** Learn about the Global Clash Cup and its competition format.
- **Embedded YouTube Video:** Watch a video related to Clash of Clans esports.
- **Event Activities:** Explore the traditional clan tournament and King of the Hill challenge.
- **Resource Links:** Access Clash Pulse and the Clash of Clans Wiki.
- **Custom Styling:** A themed design with custom colors, buttons, images, and content cards.
- **Responsive Video:** An embedded video that adjusts to the available screen width.

## 🛠️ Technologies Used

- **HTML5** — Structures the webpage and its content.
- **CSS3** — Styles the layout, navigation bar, buttons, event cards, and colors.
- **YouTube Embed** — Displays an esports-related video.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Make sure `index.html`, `styles.css`, and the image files are in the correct locations.
3. Open `index.html` in your web browser.
4. Explore the website using the navigation links.

You can also open the project folder in Visual Studio Code and use the Live Server extension to preview the website.

## 🎮 Tournament Activities

### 1. Clan Clash Tournament

Clans compete in head-to-head battles. Teams consist of five players, and the clan earning the most stars advances to the next round. The website describes the event as open to Town Hall 18 players.

### 2. King of the Hill

A competitive challenge where clan members compete in one-versus-one battles. The website concept describes a maximum of 50 participants and a $500 prize for the winner.

*These tournament formats and prizes are presented as part of the website concept, not as verified details of an officially organized event.*
